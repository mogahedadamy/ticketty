## أصحاب المصلحة

كل تقييم أثر يحدد الأثر على المستثمر، الجهة الحكومية/المنظم، مزود الدفع، شركة النقل، الوكيل/البائع، والمسافر دون خلط أدوارهم أو مشاركة بيانات غير لازمة.

## قاعدة المصدر

1. رابط رسمي + تاريخ وصول + نسخة Evidence وبصمة Hash.
2. رقم الإصدار وتاريخ النفاذ وما تم إلغاؤه.
3. Requirement قابل للاختبار ومربوط بوحدة وOwner.
4. البنود غير المثبتة تبقى `Unverified` أو `Blocked` ولا يبنى عليها ادعاء امتثال.

## منشور AML رقم 8/2026

تم التحقق من وجود المنشور في [سجل بنك السودان المركزي الرسمي](https://cbos.gov.sd/ar/content/%D9%85%D9%86%D8%B4%D9%88%D8%B1%D8%A7%D8%AA-%D9%85%D8%A7%D8%A8%D8%B9%D8%AF-15-%D8%A7%D8%A8%D8%B1%D9%8A%D9%84-2023) ومن [نسخة المنشور الرسمية](https://cbos.gov.sd/sites/default/files/%D9%85%D9%86%D8%B4%D9%88%D8%B1%20%D8%B1%D9%82%D9%85%288-2026%29-%20%D8%B6%D9%88%D8%A7%D8%A8%D8%B7%20%D9%85%D9%83%D8%A7%D9%81%D8%AD%D8%A9%20%D8%BA%D8%B3%D9%84%20%D8%A7%D9%84%D8%A3%D9%85%D9%88%D8%A7%D9%84.pdf)، بتاريخ 30 أبريل 2026. وهو يلغي/يستبدل منشور 8/2014 وتعليمات لاحقة مذكورة في بند الإلغاء. بسبب ضعف OCR في النسخة الممسوحة، يلزم فحص الصفحة الأولى بصرياً قبل نقل الصياغة القانونية الكاملة لقائمة الإلغاءات.
