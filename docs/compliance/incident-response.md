# خطة الاستجابة للحوادث

## الأدوار

- Incident Commander: قيادة وتوثيق القرار.
- Security Lead: التحليل والاحتواء.
- Service Owner: استعادة الخدمة.
- Compliance/Legal: تقييم واجب الإخطار وفق مصدر نافذ.
- Communications: رسائل العملاء/الجهات دون تضليل.

## الدورة

`Detect → Triage → Contain → Preserve Evidence → Eradicate → Recover → Notify (if required) → Lessons Learned`

## قواعد إلزامية

- لا تحذف Logs أو تعيد بناء نظام مشتبه قبل حفظ Evidence.
- كل إجراء له actor/time/reason والأنظمة المتأثرة.
- تدوّر الأسرار المتأثرة وتبطل الجلسات عند الاشتباه.
- يمنع الإعلان عن خرق أو سلامة قبل تقييم موثق.
- الإخطار القانوني لا يحدد زمنه هنا حتى ربطه بمتطلب `REG-*` رسمي.

## أهداف داخلية أولية

| Severity | Acknowledge | قيادة الحادث |
|---|---:|---:|
| Critical | 15 دقيقة | فورية وعلى مدار الساعة |
| High | ساعة | خلال ساعة |
| Medium | 4 ساعات عمل | حسب الفريق |

هذه أهداف تشغيلية لا بديل عن أي مدد نظامية نافذة.

## ما بعد الحادث

RCA بلا لوم، Timeline، أثر البيانات/المال/الخدمة، Controls فاشلة، Tasks بمالكين ومواعيد، واختبار يمنع التكرار. تحفظ الأدلة وفق `data-retention-policy.md`.
